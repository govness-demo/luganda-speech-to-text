# Luganda speech-to-text

Speech recognition model for Luganda, trained on public-service call-centre recordings with consent.

## Overview

A fine-tuned speech model for Luganda with a 14% word error rate on the public-service test set. Weights, model card and evaluation scripts are in the repository.
